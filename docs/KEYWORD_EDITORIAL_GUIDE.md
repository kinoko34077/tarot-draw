# #26 タロット早見表示：日本語キーワード編集規則（78枚独立編集版）

## 目的と権利上の区別

- **編集目的**: 1カードについて代表的なタロット解釈を幅広く見渡せること。表示はカード画像左上＋右側5見出し×各4項目。元資料の文章をそのまま再現することではない。
- ユーザーから提供された `タロット_全78枚_題とキーワード一覧.md` は、第三者の早見画像を**文字起こしした可能性が高い**との申告がある（2026-10-08）。したがって、元資料は非公開の「どの一般的な意味を重視したいか」の比較用に限定する。
- 元資料の**固有の言い回し・見出しと下位語の選択配列・図の装飾/図版**を流用しない。**単語の置き換えや一対一の見出し同義語化**だけで、独立した表現/利用権が成立したと推定しない。
- 公開可能な語句は、利用条件を確認した**Tarotooのオープンデータを出発点**として独自に日本語で執筆する。テーマが重なるのは伝統的カード意味の共通性として扱い、固有表現の模倣を避ける。
- 正本は現在の [tarot-draw #26](https://github.com/kinoko34077/tarot-draw/issues/26)。従来の無許諾ブレインマップ再配信は[#21](https://github.com/kinoko34077/tarot-draw/issues/21)のHOLDを維持する。

## 1カードごとの編集フロー

1. **オープンデータを先に読む。** 正位置だけでなく逆位置、一般意味、関係/仕事/精神性の文脈を調べる。占星術対応は流派依存のため、そのまま普遍的意味に混ぜない。
2. **意味を抽象化する。** 共通する根幹や対比を5つの日本語テーマに整理する（原資料の5見出しを一対一で言い換える必要はない）。
3. **各テーマに4関連語を独自作成する。** 端的な表現にする。1語1義・不自然な日本語・意味の薄い重複・機械翻訳調・原資料への近似は避ける。裏付けがない場合は埋め草で補わず追加の適法な資料や人間の編集判断へ差し戻す。
4. **一般的意味の取りこぼしを比較する。** 元の文字起こしは非公開の比較材料に留め、一般的な意味の不足/偏りを点検する。差分をそのまま公開原稿へ移植せず、必要な意味は適法な原典で独立に裏付ける。
5. **意味と正逆の位置付けを照合する。** 「正位置＝良い／逆位置＝悪い」とは決めない。5分類は位置別の固定5枠ではない。現行ダイアログの正逆本文は別に保持する。
6. **出典と編集理由を記録する。** カードID、根拠の英語フィールド、使用した出典、翻訳上の判断、実装版の要確認語を制作時に管理する。公開リポジトリへ第三者の転載本文・ユーザー添付全体・専用画像を持ち込まない。

## 品質・受入条件

- 78枚を既存 `card_id` と一対一対応（標準78のみ）。各カード**必ず5見出し、各4関連語**。不足時は未完了とする。
- 大アルカナ22枚は一般的意味の広がりを損なわず、小アルカナ56枚の元の5語を固定見出しとして無検証で写さない。
- 主要な意味の欠落、逆位置の誤用、意味が矛盾する無関係な語句、似た表現での水増しをレビュー。
- 代表5枚（愚者、死神、悪魔、剣の3、盃のエース）はW1レビューに使用し、その判断・根拠を `docs/KEYWORD_W1_REVIEW.md` に記録。**W1の採用は全78枚の最終出荷承認とは別**。
- W1の編集方法・初期画面構造は2026-10-08に独立編集の展開基準として採用。その後、残り73枚を独立制作し `web/card-keyword-corpus.js` に収録、全78枚の出典・方法を `docs/KEYWORD_W2_PROVENANCE.md` に記録。原資料の表現/選択配列との一致を目的とせず、伝統的意味の広がりを評価する。
- 2026-10-08にユーザーは#26の通常PRマージ・Pages公開を条件付きで明示承認（Issueコメント #6052402935）。これは出典の権利保証ではない。権利・出典通知、全78枚の意味・構造・ブラウザ/回帰検証とFormal Review完了まで公開しない。
